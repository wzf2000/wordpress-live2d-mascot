# 使用文档

适用于开发候选 **3.13.0-rc.1**；当前公开正式版为 **3.12.0**。第一次使用从安装指南开始；旧版本请查看对应 Release 源码中的文档。

此候选增加贴图错误的明确提示和手动恢复，以及 **更多 → 常用互动**：按角色选择最多三个入口，只保存在当前浏览器。其余预设仍可从更多区使用，支持取消修改和恢复默认。已有的加载取消、恢复自然状态、后台试播与资源管理保持。使用方法见[互动与偏好指南](INTERACTIONS.md#配置快捷互动)，加载问题见[常见问题与维护](TROUBLESHOOTING.md#贴图错误)。

## English entry points

The plugin interface supports **en_US / zh_CN**. Development candidate **3.13.0-rc.1** adds specific texture errors and manual recovery. Under **More → Quick interaction choices**, choose up to three existing presets for each character, save in this browser, cancel edits or restore the defaults. Other presets remain available in More. Loading cancellation, Restore natural state, draft previews, resource management and administrator-only diagnostics remain available. The current public stable release is **3.12.0**. Administrators obtain Core and models separately; installation packages contain neither. Start with [setup and licensing](DISTRIBUTION.md#administrator-setup), then see [interactions](INTERACTIONS.md#loading-and-recovery-english) or [physical-device sampling](DEVICE_SAMPLING.md).
